**فایل و متن را بین دستگاه‌هایت روی شبکه محلی بفرست.** مثل AirDrop، ولی توی مرورگر — بدون کابل، بدون کلود، بدون اکانت و بدون نصب اپ.

## 🪄 چطور کار می‌کند؟

1. دراپ‌بیم را روی کامپیوترت اجرا کن → یک **QR کد** نشان می‌دهد
2. با گوشی اسکنش کن (یا آدرسش را روی هر دستگاه دیگه در همان وای‌فای باز کن)
3. دستگاه‌ها به‌صورت **خودکار همدیگر را پیدا می‌کنند** و زنده نمایش داده می‌شوند
4. روی دستگاه مقصد کلیک کن → فایل‌ها را بکش رها کن، یا متن بفرست
5. سمت مقابل **همان لحظه** دریافت می‌کند — متن دریافتی حتی خودکار کپی می‌شود

با اینترنتِ کاملاً قطع هم کار می‌کند. فایل‌ها هرگز از شبکه‌ات خارج نمی‌شوند.

## ✨ امکانات

- 🔍 **کشف خودکار دستگاه‌ها بدون هیچ تنظیماتی** — از طریق WebSocket
- 📁 درگ اند دراپ با پیشرفت واقعی آپلود (استریم روی دیسک، تا ۵۱۲ مگابایت در هر فایل)
- 💬 ارسال متن با کپی خودکار در کلیپ‌بورد دستگاه گیرنده
- 📱 ورود با QR — گوشی دو ضربه‌ای وصل می‌شود
- 🕵️ حریم خصوصی: لینک دانلود یک‌بارمصرف، پاک شدن خودکار فایل‌ها بعد از ۶۰ دقیقه
- 🏷️ اسم‌های بامزه دستگاه — به جای IP، با `SwiftOtter` و `CosmicFalcon` آشنا شو
- ✅ ۲۱ تست یکپارچه: ثبت‌نام، حضور، جریان ارسال، انقضا و لینک یک‌بارمصرف
- 🔄 CI: تست روی Python 3.11 تا 3.13 + تست دود سرور زنده + Build داکر

## 🚀 شروع سریع

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

**http://localhost:8000** را باز کن، با گوشی QR را اسکن کن و چیزی بفرست.

با داکر:

```bash
docker compose up --build
```

> هر دو دستگاه باید روی یک شبکه محلی باشند (یک وای‌فای / هات‌اسپات).

## 📖 نگاهی به API

| متد | مسیر | توضیح |
| --- | ---- | ----- |
| POST | `/api/register` | ثبت دستگاه و گرفتن شناسه |
| GET | `/qr.svg` | QR کد آدرس این سرور |
| WS | `/ws?id=...` | حضور زنده + رویدادهای دریافت |
| POST | `/api/send/{id}/text` | ارسال متن به یک دستگاه |
| POST | `/api/send/{id}/file` | ارسال فایل(ها) به یک دستگاه |
| GET | `/download/{token}` | لینک دانلود یک‌بارمصرف |
| GET | `/health` | بررسی سلامت |

## 🏗️ نکات معماری

- **بدون دیتابیس.** رجیستری کاملاً درون حافظه است — داده قرار است با پایان پروژه بمیرد.
- **پروتکل حضور WebSocket**: رویدادهای ورود/خروج برای هر دستگاه لیست شخصی‌سازی‌شده می‌فرستند.
- **آپلود استریمی**: فایل‌های ورودی در تکه‌های ۱ مگابایتی روی دیسک نوشته می‌شوند و حجم وسط راه کنترل می‌شود.
- **توکن یک‌بارمصرف**: هر لینک بعد از اولین دانلود خودش را نابود می‌کند؛ یک پاک‌کن پس‌زمینه هم فایل‌های منقضی را حذف می‌کند.
